合规抽查抽了三个月，同一个高风险分区一次都没被抽到，报告里还写着已全覆盖：抽样必须按分区分层，每个非空分区至少抽到一条记录；每层样本量由抽样策略决定，样本量不足一条时按一条处理；高风险分区应当获得更高的抽样权重；抽样过程必须可复现，同一种子连续抽样必须得到相同结果；同一条记录不得在样本中出现两次；未覆盖的分区必须按分区名称逐条列出，即使该分区没有记录也要保留并标记为未覆盖；批量抽样时每一批都必须独立计算，前一批不得影响后一批。不变量：同一种子两次抽样结果完全相同；样本集合始终是总体的子集。
